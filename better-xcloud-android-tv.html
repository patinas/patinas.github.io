Installing Better xCloud on my Android TV

24 October 2026 · 3 min read · Android, Xbox, home lab

Why stream Xbox to a TV box

I wanted Xbox Cloud Gaming on the TV without buying a console. The games run on Microsoft's servers and stream to xbox.com/play, so a small Android box can in principle play them. The Mi Box S from my last post was the test machine again. This time the job was simpler: get the Better xCloud app installed and signed in.

What Better xCloud is

Better xCloud is a free, open-source app from the developer redphx. It improves Xbox Cloud Gaming on xbox.com/play with things like 1080p streaming, a sharper picture and more control over the stream. The Android app wraps the website with those improvements built in. It needs Android 8 or later, so my Android 9 box is inside the requirement.

The app is free, the games are not

Installing the app costs nothing. Playing does. You need a Microsoft account, an Xbox Game Pass plan that includes cloud gaming, a controller that pairs with the box and a decent internet connection. The app is only the player. The subscription is what streams the games.

Installing it

The developer distributes the app only on GitHub and warns against downloading it anywhere else, so the releases page there is the one safe source. The steps on the box: download the APK, allow installs from unknown sources when Android asks, install, open. On a TV the download itself takes an extra step, since there is no normal browser flow. A USB drive or a downloader app both work.

On my box the current version, 0.24.2, installed cleanly and opened without problems. That is as far as this article's claim goes: installed and opened, on this specific box, tonight.

Sign-in, and what is not proven yet

Sign-in happens on Microsoft's own pages inside the app, with the usual device login. Better xCloud's documentation says the app never sends your Xbox account or token anywhere else. The sign-in on my box was started tonight. What I have not done yet is play a full game stream on it. The developer is direct about budget Android TV hardware: expect problems on cheap devices, and the Mi Box S is a budget box. The real test, an actual game running smoothly, is still ahead.

Safety advice if you try this

  • Download the APK only from the official GitHub releases page.
  • Turn the unknown-sources permission off again after the install.
  • Sign in only on Microsoft's own login pages.

What happens next

Next step is the streaming test: pair a controller, start a game and see whether this budget box can carry a stream. The result, good or bad, gets its own post.
